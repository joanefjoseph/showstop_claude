# Frontend

The original Weverse replica is retained. From the repository root run npm ci, npm run build, and npm run demo:built. Open http://127.0.0.1:4000/#/2a for the customer workflow. Use http://127.0.0.1:4000/operator separately for environment controls. See [the handoff guide](../SANDBOX.md).

The original five pages remain active. Styling, layout, artwork, and placeholder navigation are preserved. Billing and commit forward membership identity, and all purchased tickets are accessible.
