Results from each step fill in the forms for the next one.

GET/events/:eventId/availability

Seat map and pricing for an event. Click seats in the result to select them for locking. Try evt_123, evt_456 (GA festival), evt_999 (sold out) or evt_nope (404).

POST/membership/verify

Looks a fan up by email. Try fan@example.com, silver@example.com (max 4 seats), expired@example.com (not eligible) or nobody@example.com (404).

POST/carts/lock

Holds seats for the configured hold time. Leave the membership ID blank to see the 401, or use mem_x02 (suspended) for a 403.

PUT/carts/:cartId/billing

Attaches customer, address and a tokenised payment instrument. Use tok_decline_insufficient_funds to make the commit fail with 402.

PUT/carts/:cartId/commit

Converts the hold into an order. Re-submitting with the same idempotency key returns the same order. If the key is blank, the bridge uses commit:<cartId>.

GET/tickets/:ticketId

Mobile ticket with the current barcode. Seeded tickets: tkt_seed_rotating and tkt_seed_static (owner mem_9f3), tkt_seed_platinum (owner mem_p01).
